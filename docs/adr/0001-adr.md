# ADR-0001: ADR を人間が書く (2026-10-10 -)

## 決定

- ADR を人間が書く。

理由: LLM は ADR を書き散らかす傾向にある。また、判断を主体的に行う責任のある人間が ADR を書くほうがコミュニケーションとして適切であると考えられる。

## 検討した選択肢1: ADR を AI が書く

利点: 放置すれば管理コストは抑えられる。

選ばなかった理由: 情報が散らかって ADR の価値が薄れる。

## 検討した選択肢2: ADR を書かない

利点: ADR は基本的には残したほうがよいと考えられるが、管理不足で誤った情報がノイズになるくらいなら無くしたほうがいい可能性もある。

選ばなかった理由: あとから整理しても同じ。
